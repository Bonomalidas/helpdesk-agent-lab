---
title: Get Access to a Jira Project
topic: jira
updated: 2025-11-20
---
To join a Jira project, request access in the Access Portal and enter the project key, for example PLAT or WEB. The project admin approves the request and adds you to the project group. Access usually takes effect within one hour. You can see project admins on the project settings page. If you only need to view tickets, ask for the read-only Viewer role instead of the Member role.
